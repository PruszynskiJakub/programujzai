
## Prosty framework funkcji Claude Code

Ciągle używałem niewłaściwej funkcji [[Claude Code]] do danego zadania.  
MCP-ów, kiedy powinienem był użyć Skills.  
Slash commands, kiedy potrzebowałem Subagentów. 👀  
  
🗺️ Teraz używam tej mapy mentalnej:  
  
Potrzebujesz zewnętrznych danych? (Jira, bazy danych)  
👉🏻 MCP  
  
Potrzebujesz uruchomić coś ręcznie? (plany, szkielety UI)  
👉🏻 Slash commands  
  
Potrzebujesz głębokiej analizy? (przeglądy, audyty)  
👉🏻 Subagenty  
  
Potrzebujesz automatycznej transformacji? (dokumenty, obrazy)  
👉🏻 Skills  
  
Ten prosty framework oszczędza mi ciągłego zastanawiania się za każdym razem. ⏳
