I kept using the wrong Claude Code feature for the job.
MCPs when I should've used Skills. Slash commands when I needed Subagents.

Now I use this mental map:

Need external data? (Jira, databases) 
-> MCPs

Need to trigger something manually? (plans, UI scaffolds) 
-> Slash commands

Need deep analysis? (reviews, audits) 
-> Subagents

Need automatic transformation? (docs, images) 
-> Skills

Simple framework. Saves me from second-guessing every time.
