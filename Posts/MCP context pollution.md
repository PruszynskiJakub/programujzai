Imagine a racing horse pulling a heavy wagon.
That's your agent with 5+ MCPs loaded.

2-3 MCPs can consume ~ 20% of your context window. Every. Single. Session.

Alternatives: 
• CLI tools  - discover and delegate (github, supabase etc.) 
• Skills - replace MCP functions with scripts

Load tools when needed, not by default.
Context is finite. Treat it like it matters.
