Your Claude Code "productivity system" is slowing you down.

I had 40+ prompts. Typing / was chaos. I'd scroll, squint, give up, type manually.

The fix was embarrassingly simple:

Namespaces. Subfolder in .claude/commands = automatic prefix. /plan:feature instead of /feature-planning-thing.

Mental model. Every prompt lives in one of two buckets: - Tool (git, obsidian, figma) 
- Workflow phase 
(Meta Plan -> Code -> Test -> Review -> Document)

Now I don't search for commands. 
I think: "I'm in the Plan phase" -> /plan: ..-> done.

Took 20 minutes to reorganize. 
Saves mass stupidity every day.
